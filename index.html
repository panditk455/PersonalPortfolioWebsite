MarketPulse: Real Time Market Data Platform

Real time streaming pipeline built with Kafka and TimescaleDB that processes live Coinbase and Kraken trade feeds with exactly once in effect aggregation on top of at least once delivery. An automated Airflow reconciliation system caught a real production bug where server restarts silently dropped data, then self healed every affected minute on re run.

Secure File Transfer System

Client and server file transfer hardened against tampering, injection, deletion, and replay attacks. Uses AES GCM for confidentiality and integrity, a hybrid RSA and AES scheme to establish keys over insecure networks, plus sequence numbering, timestamping, and SHA 256 verification.

PythonCryptographyAES GCMNetwork Security
GitHub

FinLoop: Self Improving Financial Analysis Agent

A financial document analysis agent that improves itself: three collaborating agents built on the Claude API analyze, evaluate against a rubric designed before the loop was built, and optimize their own prompts. Every prompt version, score, and cost is logged for full observability, at about $0.23 per run.

PythonClaude APILLM AgentsEvaluation Frameworks
GitHub Project site

Interpretable ML: Forensic Firearm Examiner Decisions

Trained XGBoost and Random Forest classifiers on 6,000+ structured records from the Bullet Black Box Study, reaching 80.8% accuracy after correcting for class imbalance and structural missingness. SHAP values identify the primary predictors of decision outcomes, translated into a written report for a non specialist audience.

PythonXGBoostScikit LearnSHAPInterpretability
